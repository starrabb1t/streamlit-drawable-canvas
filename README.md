## Development

### Install

- JS side

```shell script
cd frontend
npm install
```

- Python side

```shell script
poetry install
```

### Run

Both webpack dev server and Streamlit should run at the same time.

- JS side

```shell script
cd frontend
npm run start
```

- Python side

```shell script
streamlit run app.py
```
